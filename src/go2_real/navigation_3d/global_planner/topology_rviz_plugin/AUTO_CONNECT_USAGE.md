# 拓扑地图工具 - 自动连接模式使用说明

## 新增功能：自动连接模式 (Auto Connect Mode)

### 功能描述
自动连接模式允许您快速创建拓扑地图，新添加的节点会自动连接到上一个节点，形成连续的路径链。

### 使用方法

1. **激活自动连接模式**
   - 在RViz的工具栏中选择拓扑地图工具
   - 在工具属性面板中，将"Mode"设置为"Auto Connect"

2. **添加节点**
   - 左键点击可行区域点云中的位置添加节点
   - 第一个节点：独立创建，无连接
   - 第二个及后续节点：自动连接到前一个节点

3. **节点特征**
   - 自动模式下的节点使用标准标签："节点_X"（与普通节点相同）
   - 节点z轴自动抬高0.3m适应机器人高度
   - **与普通节点完全一样**：可以被删除、编辑标签、手动连接
   - 所有边都显示为红色，不区分创建方式

4. **控制操作**
   - **右键**：重置自动连接链，下一个节点将开始新的连接序列
   - **Clear All**：清除所有节点和边，重置自动连接状态

### 可视化颜色说明
- **节点颜色**：
  - 蓝色：普通节点
  - 黄色：选中用于连接的节点
  - 橙色：选中用于编辑的节点

- **边颜色**：
  - 红色：所有边（不区分手动或自动创建）

### 使用场景
1. **快速创建路径**：沿着走廊或道路快速创建连续的拓扑路径
2. **巡逻路线**：创建机器人巡逻的循环路线
3. **导航骨架**：快速建立环境的导航骨架结构

### 注意事项
- 自动模式创建的节点与普通节点**完全相同**，可以：
  - 在删除模式下被删除
  - 在编辑模式下修改标签
  - 在连接模式下进行手动连接
- 删除节点会自动调整自动连接状态
- 边的连接方向根据"Bidirectional"设置确定
- 可以随时切换到其他模式进行精细编辑

### 示例工作流程
1. 选择"Auto Connect"模式
2. 点击起始位置添加第一个节点
3. 依次点击路径上的关键点，系统自动创建连接
4. 右键重置，开始创建新的路径分支
5. 保存拓扑地图

这个功能大大提高了拓扑地图创建的效率，特别适合创建长距离的连续路径。
